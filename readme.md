# 🤖 Discord Moderation Bot

A powerful moderation bot built with Python and discord.py.

---

## 🚀 Features

- ⚠️ Warning system (SQLite database)
- 👢 Kick & Ban commands
- 🔇 Mute system (auto unmute)
- 🛡️ Anti-spam protection
- 🚨 Anti-raid system
- 🗑️ Message delete logs
- ✏️ Message edit logs
- 🎫 Ticket system
- 📊 User history system

---

## 🧰 Tech Stack

- Python 3.12+
- discord.py
- SQLite database
